# JEE Ascension V5

V5 is the adaptive test-ready planner for JEE preparation.

## V5 systems
- Reality Check: enter today's available study hours; workload is judged against estimated remaining work.
- Priority Engine: combines deadline urgency, remaining work, weakness, test priority and task priority.
- Time Core: productive / break / lost timer, session history, efficiency and productive-time XP.
- Editable To-Do: add, edit, delete, complete/undo and reorder tasks; edit description, XP, unit and due date.
- Deadline Radar: unit and test deadlines; completed items leave the active queue; missed deadlines become backlog and trigger a one-time XP penalty.
- Test Hub: add/edit/delete tests, dates, priority, subjects, editable chapters, chapter prep time, readiness checklist and prep-task creation.
- Progress Board: all remembered unit deadlines and completion states.
- Weakness Bank, Revision, Question Log, Course Library, Stats and Daily Review.

## Data
All tracker data is stored locally in the browser via localStorage. Exported JSON backups are personal data; do not upload them to GitHub.
